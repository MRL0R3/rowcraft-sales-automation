# Initial service offers

These are first-client scope experiments, not claims about market averages. Confirm requirements and independently verify that the work and payment arrangement are legally permitted before accepting paid work.

## CSV Health Check — $79–99

One source CSV, one-time review. Deliverables: documented column/quality findings, a validated cleanup or normalized copy, one concise sales/refund summary, and a brief written explanation. Excludes recurring automation, integrations, data repair requiring business decisions, and accounting/tax advice. Price depends on file condition and volume.

## Reporting Automation Pilot — $149–249

One data source and one recurring report. Deliverables: reusable Python script, configurable input path, agreed monthly metrics, sample output, setup notes, and one walkthrough. Excludes hosted infrastructure, multiple data sources, ongoing support, and changes to business rules after acceptance.

## API / Workflow Integration — $400–750

For a defined integration involving one API or workflow. Deliverables and acceptance criteria are agreed after discovery; includes a small, documented implementation and handoff. Subject to data access, API terms, privacy/security review, and technical feasibility. Excludes paid infrastructure, third-party fees, and ongoing operations.

Optional support should be offered only after defining included hours, response window, channels, exclusions, and price in writing.

## Questions before quoting

- What is the source format and can a synthetic/redacted sample be shared?
- What output is needed, and how will acceptance be checked?
- How often does the report run and what is the expected row/file volume?
- Which currency, timezone/date convention, and refund semantics apply?
- Are there privacy, retention, security, or regulatory requirements?
- Where should the script run and who maintains access/credentials?
- Have the client and developer confirmed legal contract and payment eligibility independently?

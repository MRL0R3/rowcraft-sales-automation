Start the demo server

This is the React source entry, not a standalone HTML file. Opening it directly cannot load its TypeScript modules.

  1. Open a terminal in the project folder.
  2. Run cd frontend, then npm run dev.
  3. Open the local address printed by Vite, usually http://127.0.0.1:5173/.

After building, use npm run preview to serve the production version.
